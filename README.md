# Stick

Stick helps people develop skills and knowledge across several interests by
giving them one domain to focus on each day they use the app.

- During onboarding, users add their domains of interest and arrange them in
  an ordered rotation.
- The first time they open the app on a given day, it reveals today's domain.
  That choice stays the same for the rest of the day; subsequent days rotate
  through the list. Daily use is optional.
- A bottom card reads “Today you stick to:” followed by today's domain.
- The interface is a pastel, cartoon nature scene with moving clouds,
  swaying trees, and occasional butterflies. The visual reference is a
  hand-painted storybook countryside.
- The logo is a stick. A friendly twig character with eyes, arms, and legs
  lives in the scene.
- One daily notification asks whether the user spent time on their domain.

## Choices to confirm before implementation

The suggested rotation advances on the next day the user opens the app, so
missed days do not skip interests. Calendar-based rotation is the alternative.
An optional “I spent some time” check-in and a user-selected reminder time
are also suggestions, rather than confirmed requirements.
